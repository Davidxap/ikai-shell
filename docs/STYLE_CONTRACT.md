# Style contract

What the IKAI bar style promises to the fork's bar engine, and what every Ito file promises to the look. It is checked
in source by `scripts/qa/test-style-contract.sh` (checks SC-1..SC-8), which runs in `scripts/deploy.sh` before any file is copied.

## Ownership

Omarchy owns hue. Ito owns form, ink, motion and information weight. No file invents a colour: it uses the active theme and
shell tokens (`ItoConfig` `ink` / `bone` / `blood` / `warn`, the Omarchy `Commons.Color`), and may change only an alpha or pick which token.

## Files a style ships

`Style.qml`, `BarSurface.qml`, `TooltipSurface.qml`, `VisualTokens.qml`; optionally `RunPlate.qml` and `EditHint.qml`.
They live in `plugins/ito.bar/styles/itoverse/`. The engine falls back to `shibumi` when the id does not resolve (`StyleRegistry.qml`).
The engine itself (`core/`, `services/`, `Bar.qml`, `styles/shibumi/`, `ito.state`) is not edited.

## Style properties

What the engine reads from `activeStyle` (SC-1 fails if `Style.qml` stops defining any of them):
`background`, `barForeground`, `barSurfaceComponent`, `colorTransitionDuration`, `exclusiveSizeHorizontal`, `fontFamily`,
`foreground`, `sizeHorizontal`, `sizeVertical`, `tooltipGap`, `tooltipSurfaceComponent`, `urgent`, `visualTokens`.

`foreground` and `barForeground` are what other authors' plugin panels read as `bar.foreground`. They must stay the theme's own
foreground (`tokens.ink` = `Commons.Color.foreground`) at every moment of a theme change (SC-8, and `SG-T5` in `models.test.mjs`).

## Motion

One clock: `bar/modules/ItoMotion.js`. A call site names a role (`snap`, `mark`, `color`, `settle`, `arrive`, `leave`, `bleed`,
`spatialFast`, `morph`, `spatial`, `spatialSlow`, `reveal`, `world`) through `ItoAnim` / `ItoColorAnim`; `dur(ms, amp, scope)` scales by
`motionAmp` (0 / 1 / 1.7) capped per scope (bar 1.2, panel 1.4, eye 1) and is 0 when motion is off. A functional time (a `Timer`
interval, a cleanup, a dwell) uses `functional(ms)`: never scaled, never 0 (SC-5). Literal `duration:` values only ratchet down (SC-4).

## Layering and elevation

Layers over a surface come from `ItoSurfaces.overlay(role, S, fg, accent)` (hover, press, selected, separator, pillFill, pillBorder,
shadow, idle). `surfaceLayering: classic` (default) keeps the original literals. Elevation is a hard offset ink shadow
(`ItoElevation.qml`, flag `elevation: flat | ink`), levels 0..3, no blur.

## Gates

- BAR_STATIC: no clock runs idle on the bar. Panel clocks are `running: live`. A new clock file must be on a list in
  `scripts/qa/check-live-gates.sh` (SC-7). Documented exemption: the fog Timer in `ItoPlate.qml` (opt-in, off by default).
- Flags: every new behaviour sits behind an `ito-config` key whose default is today's look. Rollback is the flag.
- No colour literals in `styles/itoverse/*` or `bar/modules/*.qml` beyond the recorded debt (SC-3, `style-contract.debt.json`).
- No property named `on[A-Z]...` (it is parsed as a signal handler, SC-6).
- Never use an unversioned `import QtQuick` in files that use `Color.`: Qt 6.12 shadows `qs.Commons.Color` (see `scripts/qa/check-qt-color.sh`).
